One line: a robot vacuum files a noise complaint against its own owner for vacuuming while it vacuums. The joke lands on the reversal — the machine that makes the noise complains about the noise.

`main.py` writes that single line (79 characters, UTF-8, no trailing newline) to `/output/entry.txt`. Python standard library only, no network, the same bytes on every run. It refuses to write anything that is not one line of 1 to 200 characters.

## Run it

```sh
python3 main.py                              # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py       # writes out/entry.txt
```
